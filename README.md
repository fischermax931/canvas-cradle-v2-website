## About Canvas & Cradle

Canvas & Cradle is a website template for small businesses, written in plain HTML, CSS, and JavaScript. It gives you a ready-made foundation for putting a company, service, or product in front of visitors, organized around a single landing page that covers pricing, common questions, and a place to collect leads.

The template suits teams that would rather avoid a heavy application stack and still want a lightweight, adjustable web presence. A responsive layout, a dark canvas look, a cursor spotlight effect, and handling for reduced-motion preferences and touch screens keep the experience usable across modern devices.

## Usage

1. Open the main HTML page in a browser to inspect the default layout.

3. Adjust the pricing, FAQ, and landing page sections to match your offering.
4. Connect the lead capture form to the service or endpoint used by your business.
5. Review the terms and privacy pages before publishing.

The template can also serve as a starting point for additional pages in the included collection. When you move the site to another host, keep the related HTML, CSS, and JavaScript files together.

## Configuration

Canvas & Cradle is configured through its files rather than a separate runtime configuration system. Make your changes directly in the project files:

- **HTML:** Edit page content, navigation, pricing, FAQs, forms, and legal-page text.
- **CSS:** Modify colors, spacing, typography, responsive behavior, and the dark canvas presentation.
- **JavaScript:** Adjust interactive behavior such as the cursor spotlight and form-related interactions.
- **Static hosting:** Configure the repository or hosting provider to serve the project directory as a static website.

If the project includes multiple HTML pages, keep their links consistent when changing filenames or deployment paths.

## FAQ

### Who is Canvas & Cradle for?

It is intended for small businesses, independent teams, and creators who need a responsive website or landing page template.

### How do I preview the template?

Clone or download the repository and open its primary HTML file in a modern browser.

### Can I host it on GitHub Pages?

Yes. The project is designed around self-contained web pages and can be published through GitHub Pages or another static hosting service.

### Where do I change the business content?

Edit the relevant HTML files. This includes the landing page copy, pricing details, FAQ entries, navigation, forms, and legal pages.

### How is the lead capture form connected?

The template provides a lead capture form integration point. Configure it for the service or endpoint selected for your website before publishing.

### Does the interactive effect work on touch devices?

The design includes touch-device support, and its motion behavior accounts for reduced-motion preferences.

### What should I check if the layout looks incorrect?

Confirm that the CSS and JavaScript files remain in their expected locations, then reload the page in a current browser. If the site is hosted in a subdirectory, verify that asset and page links use the correct paths.

### How do I get updates?

Check the repository for newer releases or changes, then compare them with your customized files before updating the deployed site.
